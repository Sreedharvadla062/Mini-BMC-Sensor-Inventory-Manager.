# Mini-BMC Sensor & Inventory Manager

## Overview
This project simulates a simplified Baseboard Management Controller (BMC) firmware system.

It includes:
- Sensor monitoring (CPU & GPU temperature simulation)
- Inventory management display
- Threshold-based alert system
- Log generation

## Technologies
- C Programming
- Linux Environment
- Embedded Systems Concepts

## Project Structure
mini-bmc-sensor-inventory-manager/
 ├── src/
 │   ├── main.c
 │   ├── sensor_manager.c
 │   ├── inventory_manager.c
 ├── logs/
 ├── Makefile
 └── README.md

## Build
make

## Run
mkdir logs
./mini_bmc
